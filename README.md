# Assignment 1: Problem Solving with TypeScript & OOP

This assignment focuses on strengthening core TypeScript concepts and Object-Oriented Programming (OOP) through practical problem-solving. It includes eight coding problems covering functions, optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, access modifiers, inheritance, and asynchronous programming with Promises.

Additionally, it includes two technical blog posts explaining important TypeScript concepts with practical code examples.

## Blog Posts

1. [Type Aliases vs. Interfaces in TypeScript](./type-vs-interface.md)
2. [Understanding Access Modifiers in TypeScript OOP](./access-modifiers.md)
